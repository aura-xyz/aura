ローカルファーストのデスクトップ AI エージェントアプリ。Tauri 2.0 + React 19 + TypeScript で構築されています。多数のクラウドモデルプロバイダーとローカル推論フレームワークに対応し、セッション・資格情報・設定はすべて端末内に保存されます。

## 機能

- **複数プロバイダー対応**：17 社のプロバイダープリセットを内蔵（OpenRouter、OpenAI、DeepSeek、月之暗面 Kimi、智谱 GLM、MiniMax、硅基流动、零一万物、百川、阶跃星辰、Groq、xAI、Together、阿里百炼、火山方舟、腾讯混元、およびカスタム OpenAI 互換エンドポイント）。プロバイダーを選ぶと公式 API アドレスが自動入力されます
- **ローカルモデル**：Ollama と llama.cpp server に対応。アプリ内でサービス状態の確認、モデルのpull、ダウンロード進度の表示が可能
- **モデルカタログとお気に入り**：プロバイダー選択後、ワンクリックで全モデル一覧を取得し、検索とチェックでお気に入り登録。お気に入りはプロバイダー別にグループ化され、对话ページでいつでも切り替え可能
- **3 つの作業モード**：对话（Chat）、规划（Plan）、执行（Build）。タブで切り替え、送信ごとにその時点で选択中のモードが適用されます
- **任务清单（TODO）**：规划モードが実行可能なステップを生成しサイドバーに表示。执行モードが順次推进し、状態をリアルタイム更新
- **複数ワークスペースのセッション**：サイドバーがワークスペースごとにセッションを整理。新規作成・切り替え・削除のほか、右クリックコンテキストメニューと行内リネーム（ディスク上のファイルは操作しません）。最初のメッセージを送信するとワークスペースはロックされ、1 つの对话は 1 つのワークスペースに一意対応します
- **自动降级**：主モデルが制限・故障した场合、降级チェーンに従って次の利用可能なモデルに自动切り替えし、理由を通知
- **ストリーミング出力**：SSE 増分レンダリング、タイプライター效果、生成はいつでも停止可能
- **充実のツールセット**：`list_files` / `read_file` / `search_workspace` で読み取り・検索、`write_file` / `string_replace` / `replace_lines` でファイル変更、`run_script` でコマンド実行。アクションカードでリアルタイム表示、失败時の再试行と诊断通知付き
- **コンテキスト管理**：コンテキスト上限に近づくと历史を自动压缩し、长い对话でも中断なし。任务清单は独立して保存され、压缩でも失われません
- **パス許可リスト**：ワークスペース以外にも、モデルに読み書きを許可するディレクトリを追加できます（スキルディレクトリならモデル自身が技能を管理）。システムディレクトリや鍵ディレクトリは**常に拒否**され、`デスクトップ`や`ドキュメント`のようなプライバシーに関わるフォルダは確認を求めてから追加します
- **操作タイムライン**：サイドバーの「トレイス」で、その会話でモデルが行ったすべての操作を時系列で記録——呼び出したツール、引数、所要時間、どこでブロックされたか。会話ごとに分離され、検索でき、Markdown で書き出せます
- **スキル（Skills）**：再利用可能な手順を `SKILL.md` としてワークスペースや本机に置くと、モデルが必要に応じて読み込みます。読み込まないスキルはコンテキストを消費せず、スキルは権限を狭めることしかできず、モードの制限を回避できません。Skills ページには全スキルとその来源（ワークスペース / ローカル / マーケット / 内蔵）が並び、有効化・無効化・削除ができます。スキルマーケットはワンクリックでインストールできますが、その前に**静的チェック**を行い、スキルが要求する権限とパッケージ内の危険なコマンドやプロンプトインジェクションの記述を一覧表示し、確認したうえで導入します。任意の GitHub リポジトリを追加のソースとして登録したり、SkillHub のような第三者スキルライブラリを接続することもできます（**ソースで絞り込み、ソース内検索**）。
- **设定ページ**：サイドバーは收纳・展开可能。设定は外観・モデルサービス・一般に分かれ、ライト/ダークテーマ切り替えとグローバルルール设定に対応
- **ローカル永続化**：セッション历史、任务清单、设定はローカル SQLite に保存。API キーは Windows DPAPI で暗号化してから保存されるため、クラウドへの依存はありません

## 作业モード

タブでモードを选択します。**送信ごとにその时点で选択中のモードが适用され、いつでも変更可能です。** 3 つのモードの違いは、许可される操作の范围とプロンプトの侧重です：

| モード | 定位 | ファイル読み取り | ファイル変更 | コマンド実行 | 侧重 |
| --- | --- | :---: | :---: | :---: | --- |
| 对话 | 纯粋な问答 | ✓ | — | — | 直接回答、流程なし |
| 规划 | 计划の作成 | ✓ | — | — | まず现状を调查し、実行可能なステップを提示 |
| 执行 | 実作业 | ✓ | ✓ | ✓ | 任务清单に従って顺次推进し、进捗を更新 |

权限はプログラム侧で强制検证されます：对话・规划モードでモデルが书き込み系ツールを呼ぼうとしても拦截され、执行モードへの切り替えが促されます。サイレント失败にはなりません。

任务清单は全ステップ完了後に自动的にクリアされ、セッションとともに保存され、再起动后も复元されます。

## 内蔵プロバイダー

| カテゴリ | プロバイダー |

| 国际 | OpenRouter、OpenAI、DeepSeek、月之暗面 Kimi、Groq、xAI Grok、Together AI |
| 国内 | 智谱 GLM、硅基流动 SiliconFlow、零一万物 Yi、百川智能、阶跃星辰 Step、MiniMax 稀宇、阿里百炼通义千问、火山方舟豆包、腾讯混元 |

## 设定

设定ページの「モデルサービス」で、プロバイダーごとに 1 枚のカードを设定します：

1. モデルプロバイダーを选択（公式 API アドレスが自动入力されます）
2. そのプロバイダーの API キーを入力
3. 「获取模型列表」をクリックして利用可能なモデルを取得し、検索とチェックで必要なモデルをお気に入りに追加

キーはローカル SQLite データベースにのみ保存され、Windows DPAPI で暗号化されます（现在の Windows ユーザーに绑定）。第三者サービスへアップロードされることはありません。Windows ユーザーを変更したり OS を再インストールした场合は、各プロバイダーのキーを再入力してください。

ローカルモデル（Ollama / llama.cpp）に API キーは不要です。ローカルサービスが起动していることを确认してください。

> **环境変数について**：`OPENROUTER_API_KEY` は OpenRouter の过去互換のフォールバックとしてのみ保持されています。他のプロバイダーのキーは设定ページで入力してください。
